# Git实验笔记
## 命令理解
### git add
将工作目录的修改添加到**暂存区**，标记需要提交的改动，改动尚未存入版本库。

### git commit
把暂存区的改动生成快照，保存到**本地版本库**，生成提交记录；仅保存在本机，不会上传远程仓库。

### git restore
用暂存区或版本库中的文件，覆盖工作目录，丢弃工作区未暂存的修改。
- `git restore 文件名`：撤销工作区修改
- `git restore --staged 文件名`：将文件从暂存区移出

## 三大工作区
1. 工作目录：直接编辑文件的区域
2. 暂存区：临时存放待提交修改
3. 版本库：`.git`目录，保存完整版本历史

## 第一次Git实验总结 
1. git add 的作用是： 把工作区的文件改动添加到暂存区，告诉 Git 要记录这些修改，为后续提交做准备，改动此时还没有保存到仓库版本。
2. git commit 的作用是：将暂存区里的改动保存到本地 Git 仓库，生成一个新的版本快照，永久记录本次修改，仅保存在本机。
3. git restore notes.md 的作用是：撤销工作区里对 notes.md 文件的修改，把文件恢复到暂存区或者最近一次 commit 的状态，丢弃还没 add 的改动。
4. commit 与 push 的区别是：commit 只是在本地仓库生成版本记录，改动只存在你电脑上；push 是把本地已经 commit 好的版本上传到远程仓库，把本地版本同步到服务器，其他人才能看到。
